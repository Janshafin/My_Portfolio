# Jan Shafin — Portfolio

Personal portfolio showcasing Ethereum systems, AI agents, and web3 development.

**Live:** https://janshafin.github.io/My_Portfolio/

## Features

- **3D Animated Characters**: Cartoon 3D figurines with scroll-driven ring carousel
- **Dynamic Colour System**: Page background transitions through four character colours
- **Responsive Design**: Optimized for desktop and mobile
- **Smooth Scrolling**: Using Lenis scroll library
- **Onchain Systems & AI Agents**: Showcasing web3 expertise

## Technologies

- Vanilla JavaScript (no build step)
- CSS 3D Transforms
- Google Fonts (Archivo)
- Responsive layout with `--vw` unit system

## Content Sections

- **Intro**: Hero with 3D character carousel
- **Builds**: Selected projects and repositories
- **About**: Background and experience
- **Skills**: Onchain systems, product, AI agents
- **Interests**: Current focus areas
- **Contact**: Email and social links
